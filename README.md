### 1. Общее описание

Данный Telegram-бот представляет собой бот-помощник службы поддержки, который:

Приветствует пользователя и предлагает задать вопрос;

Показывает меню часто задаваемых вопросов (FAQ) с кнопками;

Отвечает на типовые вопросы (оформление заказа, статус, отмена, повреждённый товар, доставка, поддержка);

Перенаправляет нетиповые вопросы оператору;

Обеспечивает двустороннюю переписку между пользователем и оператором через пересылку сообщений.

---

**_2. Структура и функциональность_**

## 2.1 Структура и функциональность

### 3.1. Команда `/start`
**Обработчик:** `send_welcome(message)`

**Назначение:** приветствие нового пользователя.

**Действие:**
- Отправляет приветственное сообщение:
  > «Привет! Я твой Telegram бот-Помощник! Напиши мне свой вопрос, а я постараюсь тебе на него ответить.»

**Триггер:** команда `/start`.

---

### 2.2. Команда `/help`
**Обработчик:** `sendhelp(message)`

**Назначение:** вывод меню часто задаваемых вопросов (FAQ).

**Действие:**
1. Отправляет сообщение «Выберите вопрос» с клавиатурой.
2. Дополнительно отправляет подсказку «Пришлите свой вопрос!» (см. примечание в разделе 6).

**Триггер:** команда `/help`.

---

### 3. Схема взаимодействия_

Пользователь ──/start──▶ Бот: приветствие
            ──/help───▶ Бот: меню FAQ
            ──кнопка──▶ Бот: ответ на типовой вопрос
            ──"Другое"─▶ Бот: "Напишите вопрос оператору"
            ──сообщение▶ Бот: пересылка оператору ──▶ Оператор
                                                     │
Оператор ──реплай на пересланное сообщение──▶ Бот ──▶ Пользователь

## 4. Ограничения и особенности реализации

| Особенность | Описание |
|---|---|
| Режим ожидания оператора | Активируется **только** через кнопку «Другое». Действует на одно сообщение. |
| Типы контента | Поддерживаются только `text`, `photo`, `document`. Голосовые, видео, стикеры не обрабатываются. |
| Ответ оператора | Обязательно **реплаем** на пересланное сообщение, иначе бот предупредит оператора. |
| Анонимность | Ответ оператора копируется (`copy_message`), а не пересылается — личность оператора скрыта. |
| Состояние | Хранится в памяти (`set`). При перезапуске бота сбрасывается. |

## 5. Итоговая таблица обработчиков

| Обработчик | Триггер | Назначение |
|---|---|---|
| `send_welcome` | `/start` | Приветствие |
| `sendhelp` | `/help` | Меню FAQ |
| `on_click` | любой callback | Ответы на кнопки |
| `relay_to_operator` | сообщение от пользователя из `waiting_for_operator` | Пересылка вопроса оператору |
| `relay_from_operator` | сообщение от `OPERATOR_ID` | Ответ оператора пользователю |
| `getquestions` | (не активен) | Заглушка обработки вопроса |
