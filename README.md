**_1. Общее описание_**

Данный Telegram-бот представляет собой бот-помощник службы поддержки, который:

Приветствует пользователя и предлагает задать вопрос;

Показывает меню часто задаваемых вопросов (FAQ) с кнопками;

Отвечает на типовые вопросы (оформление заказа, статус, отмена, повреждённый товар, доставка, поддержка);

Перенаправляет нетиповые вопросы оператору;

Обеспечивает двустороннюю переписку между пользователем и оператором через пересылку сообщений.



**_2. Структура и функциональность_**

Команда /start
Обработчик: send_welcome(message)

Назначение: приветствие нового пользователя.

Действие:

Отправляет приветственное сообщение:

«Привет! Я твой Telegram бот-Помощник! Напиши мне свой вопрос, а я постараюсь тебе на него ответить.»

Триггер: команда /start.




Для установки всех нужных биолиотек впишите в консоль - pip install -r requirements.txt
